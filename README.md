# policy

네모팩토리 앱들의 개인정보처리방침 · 고객지원 페이지. GitHub Pages 로 공개된다.

`https://wingoblin.github.io/policy/<슬러그>/`

## 고칠 때

1. `src/<슬러그>.html` 을 고친다 (본문만 들어 있다)
2. `node build.mjs`
3. 커밋 & 푸시 — 1~2분 뒤 반영

`<슬러그>/index.html` 은 생성물이라 직접 고쳐도 다음 빌드에 덮어써진다.

## 🛑 예고 기간을 적지 마라(사용자 2026-09-29)

「불리한 변경은 **7일 전** 예고」 같은 기간 약속을 **어느 방침에도** 넣지 않는다. 바뀜 줄은 이것 하나다 —
「이 방침이 바뀌면 이 페이지에 시행일을 고쳐 알립니다. 바뀐 방침은 이 페이지에 올린 날부터 효력이 생깁니다.」
(법 의무가 아니라 작성지침 권고다. 적어 두면 그 약속이 광고를 막는다 — 살래말래 전면광고가 그걸로 일주일 밀렸다.)
광고를 넣을 땐 **같은 날 방침을 고치고 시행일을 그날로** 한다. 예고 문단을 따로 두지 않는다.

## 앱 추가할 때

1. `apps.json` 에 `{ "slug": "...", "title": "..." }` 한 줄
2. `src/<슬러그>.html` 에 본문 작성 (`<h1>` 부터, `<html>`·`<head>` 없이)
3. `node build.mjs`

## 출시 전 앱

이 레포는 공개다. 커밋 기록도 함께 공개되므로, 아직 스토어에 없는 앱의 방침을
여기 올리면 그 앱을 만들고 있다는 사실이 새어 나간다. 파일을 지워도 기록에는 남는다.

출시 전 초안은 `_drafts/` 에 둔다. 이 폴더는 git 이 무시한다.
스토어에 올리는 날 `src/` 로 옮기고 `apps.json` 에 추가한다.

## 주의

- 스토어 콘솔(Play·App Store Connect)에 등록된 URL 이다. 슬러그를 바꾸면 링크가 죽는다.
- 방침 URL 이 죽으면 스토어 정책 위반이다.
