変更のお知らせ — Android 版にも広告が入ります
バージョン 1.0.3 から、Android 版にも iPhone・iPad 版と同じ場所に広告が表示されます — 一覧画面下のバナー、検査・保存・一括処理中の中サイズ広告、保存完了後の全画面広告です。このときから Android 広告 ID（AAID）が広告ネットワークに渡され、広告事業者のコードが端末にインストールされているアプリを確認できるようになり、広告ネットワークに Liftoff Monetize が加わります。変わる点はすべて第6項に記載しました。それ以前の Android 版には広告設定が入っておらず、広告リクエストは一件も送信されていません。その版を使い続ける限り、今後も送信されません。

ひとことで。 Cover It には会員登録やログインがなく、氏名・連絡先・写真・動画を受け取る当社のサーバーもありません。選んだ写真や動画はこの端末の中だけで編集され、外部に送信されることはありません。ただし、アプリには広告が表示され、Unity（Android 版は Liftoff を含む）が広告の配信と測定のために端末・広告・接続情報を処理する場合があります（第5～7項）。

1. 収集する個人情報

当社が氏名・連絡先・メールアドレス・生年月日などの個人情報を直接収集することはありません。アカウント機能がないため、登録やログインの手続き自体が存在しません。利用者がご自身でメールを送信してお問い合わせいただいた場合にのみ、そのメールにご記入の返信先を当社が受け取ります（11項）。

当社は写真・動画や本人確認情報を受け取るサーバーを持っていません。ただし、広告が表示される際には、第三者サービスである Unity LevelPlay および Unity Ads（Android 版は Liftoff Monetize を含む）が第6項の情報を自動的に処理する場合があります。当社は広告管理画面で、表示・クリック・収益などの集計された実績を確認する場合があります。

2. 写真と動画について

このアプリは、隠したいファイルをアプリ内で直接選んで編集します。そのため写真へのアクセス権限と写真への保存権限が必要です。

  • 読み取り — 隠したい写真や動画を一覧に表示し、選んだファイルを編集画面で開くために使います。Android では写真全体ではなく選択した項目のみを許可しても、そのままご利用いただけます。
  • 保存 — 隠す処理を終えた結果は、利用者が「保存」をタップしたときにのみ写真に保存されます。
  • 元のファイル — 元のファイルを削除したり上書きしたりすることはありません。結果は常に新しいファイルとして保存されます。
  • 送信 — ぼかし・モザイク・ステッカーの処理はすべて端末の中で計算します。写真と動画が当社のサーバーやその他の場所にアップロードされることはありません。

撮影場所の位置情報は読み取りません。隠す処理に必要がないため、その権限を要求しない造りにしています。カメラとマイクも使いません — このアプリは撮影を行わず、すでにある写真や動画を編集するだけです。

3. 顔の自動検出について

顔を自動で見つけて隠す機能は、すべて端末の中で計算します。解析のために写真や動画が外部に出ることはありません。

  • 誰であるかを識別しません。このアプリは「どこに顔があるか」だけを探します。人物を特定したり、他の写真の顔と照合したりする機能はありません。
  • 顔の特徴量を作成・保存しません。見つけた位置は画面に隠し要素を描くためだけに使われ、編集を終えると残りません。

4. 端末にのみ保存されるもの

  • アプリの設定 — 保存画質、画面の明るさ（システム・ライト・ダーク）、最初の案内を見たかどうか。
  • 選んだ言語 — 言語画面で選んだ値1つを、アプリ自身のフォルダに保存します。
  • 評価のお願いに関する記録 — アプリを初めて起動した時刻、評価をお尋ねした回数と最後の時刻、「あとで」で延期された期限、「今後表示しない」を選ばれたかどうか。同じ案内を頻繁に表示しないための日時と回数のみで、利用者を特定することはできません。
  • 一時ファイル — 保存した結果を完了画面に表示するための控え（作成から1時間が過ぎるとアプリが削除します）、編集のために複製した元ファイル、人物だけを切り抜いた画像。後の2つは次にアプリを起動したときにすべて削除されます。

これらはすべて利用者の端末の中にのみ存在します。当社や広告事業者に送信されることはなく、当社が閲覧することもできません。アプリを削除すると、すべて一緒に消えます。

5. アプリが外部に行う通信

アプリは次の通信を行います。写真・動画・編集内容は、そのいずれにも送信されません。

  • 最新バージョンの確認 — 起動時に1回、当社が公開しているバージョン案内ファイルを読み込みます。重大な不具合を修正した際に、古い版を使い続けないようご案内するためのものです。その通信に当社が利用者の情報を含めることはありません。ただしウェブページを開くときと同様に、そのファイルを置いているホスティング事業者のサーバー記録に、接続元のIPアドレスと端末の一般的な接続情報が残る場合があります。読み込みに失敗した場合、アプリは通常どおり起動します。
  • このポリシーを開くとき — 設定画面でプライバシーポリシーをタップすると、端末のブラウザが開いてこの文書を読み込みます。そのときも同じ性質の接続記録が残る場合があります。
  • 広告リクエスト — 広告の読み込み・表示と実績測定のため、Unity の広告サーバー（Android 版は Liftoff の広告サーバーを含む）と通信します。処理される情報と選択肢は第6項で説明します。広告を読み込めなくても、編集と保存は通常どおり利用できます。
  • 購入の通知 — Android でアプリ内課金が完了すると、商品 ID・表示価格・注文番号が当社のサーバーに送信されます。販売があったことを知るためのもので、利用者を特定できる情報は含みません。iOS では Apple から直接通知されるため、アプリからは送信しません。

6. 広告について

無料サービスの運営のため、アプリには広告が表示されます。写真・動画の一覧画面の下部にはバナー広告が、顔またはナンバープレートの検出中・結果の保存中・複数枚をまとめて隠している間には中型の長方形広告が、保存完了後にはインタースティシャル広告が表示される場合があります。アプリ内課金（Cover It Pro）をご購入いただくと、一覧画面下部のバナー広告は表示されません。

広告は Unity LevelPlay（旧 ironSource）というメディエーションサービスを通じて表示されます。メディエーションは、複数の広告ネットワークの中からその都度広告を出すところを選ぶ仲介の役割を担います。現在接続しているネットワークは次のとおりで、今後増減することがあります。

  • Unity Ads — Unity Technologies（iPhone・iPad・Android）
  • Liftoff Monetize（旧 Vungle）— Liftoff Mobile, Inc.（Android）

これらの広告事業者とその広告・測定パートナーは、広告リクエスト時に次の情報を自動的に処理する場合があります。

  • 識別子 — IDFV・アプリセット ID などのアプリ単位の端末識別子、そして広告識別子 — iOS はトラッキングを許可した場合の IDFA、Android は Android 広告 ID（AAID）です。いずれも端末の設定でいつでもリセットまたは使用停止できる値です。
  • 端末・接続情報 — IP アドレス、IP から推定されるおおよその国・地域、端末のメーカーとモデル、OS とバージョン、言語、タイムゾーン、画面・ネットワーク情報、アプリ名とバージョン。
  • 広告利用情報 — 広告のリクエスト・表示・クリック・閉じる操作・エラー、広告経由のインストールの有無など、広告効果の測定と不正防止に必要な情報。
  • インストール済みアプリの情報（Android）— 広告事業者のコードが、端末にどのアプリがインストールされているかを確認できます。広告を見てインストールしたかを数えたり、すでにインストール済みのアプリの広告を再表示しないために使われます。Cover It が読むものではなく、当社にも届きません — アプリのコードにはインストール一覧を問い合わせる箇所が一つもなく、この動作は広告事業者のコードの中で行われます。

これらは広告の配信、表示頻度の調整、効果測定、不正防止、サービス改善に使用され、許可されている場合はパーソナライズ広告や他社のアプリ・ウェブサイトをまたぐ広告測定にも使用されることがあります。写真・動画・顔・ナンバープレート・編集内容が広告事業者に送信されることはありません。

iOS では広告 SDK を開始する前に、App Tracking Transparency（ATT）によるトラッキング許可を求めます。拒否すると IDFA は利用できませんが、広告は引き続き表示される場合があります。許可は 設定 → プライバシーとセキュリティ → トラッキングでいつでも変更でき、広告内のプライバシーアイコンから広告事業者が提供する選択肢を利用できます。

Android にはトラッキング許可の画面がありません。代わりに端末設定の広告 ID の項目がその役割を果たします。設定 → Google → すべてのサービス → 広告 で「広告 ID を削除」を押すと（メーカーによっては 設定 → プライバシー → 広告）、広告 ID は広告事業者に渡されなくなり、広告はパーソナライズされない広告に切り替わります。アプリを再インストールする必要はなく、オフにしてもアプリのすべての機能をそのまま使えます。

Android で広告のために加わる権限
広告 ID の読み取り（AD_ID）— 広告ネットワークがパーソナライズ広告に使う端末の広告 ID を読むためのものです。Android 13 以降はこの権限を宣言しないとその値を読めません。読み取るのは広告ネットワークで、当社ではありません — 当社は受け取りも保管もしません。この権限はインストール時に自動で付与され、確認の画面は表示されません。このほか広告部品が、広告を読み込むためにインターネット接続とネットワーク状態確認の権限を使います。

Unity とそのパートナーは広告表示時に、国外を含む地域でネットワークを通じて上記情報を処理する場合があります。保存・削除の基準は各社のポリシーと法的義務に従います。詳細とプライバシーに関する請求方法は、Unity のプライバシーポリシー · Liftoff のプライバシーポリシーをご確認ください。

Google Play「データ セーフティ」に記載した内容
Google は同じ値を独自の分類でまとめて表示します。Android 版で申告した項目は デバイスまたはその他の ID（広告 ID）・アプリのアクティビティ（アプリの操作・インストール済みアプリ）・アプリの情報とパフォーマンス（クラッシュログ・診断）・おおよその位置情報で、すべて上記の広告一覧と同じ値であり、広告目的で広告事業者が直接読み取ります。これに第5項の購入の通知が金融情報（購入履歴）として加わります — 当社のサーバーに届くのはこれだけで、他へは渡しません。アカウントがないため、どの項目も利用者の身元とは結びつきません。

7. 第三者提供

当社が写真・動画や本人確認情報を第三者に提供することはありません。ただし広告配信のため、第6項の情報が Unity（Android 版は Liftoff を含む）とその広告・測定パートナーへ自動的に送信・処理される場合があります。当社が受け取る広告実績レポートは主に集計されたものです。

8. 子どものプライバシー

このアプリは子ども向けのサービスではありません。氏名や生年月日を求めないため、利用者の正確な年齢を判定できません。保護者の同意が必要な年齢の方は、保護者と一緒にアプリおよび端末のトラッキング・広告設定をご確認ください。

9. 利用者の権利

当社には氏名や連絡先で管理する利用者アカウントがありません。端末に残る設定と一時ファイルは、アプリを削除すればすべて消去されます。広告情報に関する権利は、広告内のプライバシー機能または第6項にリンクした各広告事業者のポリシーから行使できます。Android では端末の設定で広告 ID を削除することもできます（第6項）。当社にお問い合わせいただければ、可能な範囲でご案内します。

10. ポリシーの改定

本ポリシーを改定した場合は、公表日と施行日をこのページに掲載します。広告・アプリ内お問い合わせ画面・アプリ内課金に関する変更は2026年9月15日に公表・施行しました。Android 版の広告（広告 ID・インストール済みアプリ・Liftoff Monetize）に関する今回の変更は2026年9月22日に公表し、その広告が入った Android 版 1.0.3 から適用します。今後、利用者にとって不利になり得る変更は事前にお知らせします。
