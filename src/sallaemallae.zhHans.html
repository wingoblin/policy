Faux Haul 隐私政策

生效日期：2026年10月14日
联系方式：contact@nemofactory.co.kr

一句话概括
Faux Haul（韩文名“살래말래”）无需注册、无需登录，我们也不运营任何收集您信息的服务器。您的信息没有地方可以发送和积累。您在应用中创建的一切（心愿单、购物袋、订单记录）都只保存在您的设备上（第2条）。

本应用实际上不销售任何东西——请先阅读
Faux Haul 是一款虚拟购物模拟。应用中的所有品牌和商品都是虚构的，不是真实的商标或商品。不会发生真正的支付，也不会寄送任何东西。点击“支付”不会转移任何资金，应用也无法访问您的银行卡、银行账户或支付服务。详情见第3条。

本应用含有广告
为了让应用保持免费，其中含有广告。广告网络会读取您设备的广告标识符，而应用为您记录的任何内容（心愿单、购物袋、订单、搜索）都不会传给它。会读取什么、以及如何关闭个性化，写在第7条。没有任何功能需要看广告才能使用。

1. 我们收集的个人信息

没有。我们不收集姓名、联系方式、电子邮箱地址、出生日期、地址或支付信息。应用没有账号功能，因此完全没有注册或登录。

我们不运营任何收集您信息的服务器。没有账号，就没有地方会积累关于您的任何东西。应用向互联网发出的每一个请求都完整列在第8条，唯一会到达我们这里的，是Android 版发出的一行“刚卖出一件商品”通知——其中不含任何能识别您的信息（第8条）。

2. 保存在您设备上的数据

以下数据保存在您设备上应用专用的存储空间中，不会离开设备。

  • 心愿单——您保存的商品 ID。
  • 最近浏览——您打开过的商品 ID（最多60条）。
  • 购物袋——商品 ID 以及您选择的颜色、尺码和数量。
  • 订单记录——您订购的商品、金额和时间。这些都是虚拟订单（第3条）。
  • 收货地址——您在下单页面输入的姓名、电话号码、地址和备注。这是模拟用的输入，不会发送到任何地方（第3条）。
  • 头像——您在 MY 页面设置的照片的文件名。照片文件本身放在应用专用文件夹中（第4条）。
  • 昵称——您在 MY 页面输入的名字。留空时保持为 Unknown。
  • 最近搜索——您在搜索框中输入的词语（最多10条）。
  • 语言设置——是否跟随设备语言，或您选择的语言。
  • 余额——应用内使用的虚拟金额、您最后一次领取每日补充的日期、当天看广告补充的次数、应用内购买附带的一次性赠送是否已发放，以及您最后一次领取 VIP 订阅每日份额的日期（第3条）。同样的值还会保留一份备份。这不是真钱，也不会离开您的设备。
  • 应用内购买记录——是否已购买底部横幅移除、是否订阅了 VIP，以及已到账的补充的商店交易 ID（最近60条），以免同一笔付款被重复到账。这些不会离开您的设备。
  • 评分邀请记录——应用首次打开的时间、评分／评价邀请显示的时间和次数，以及您在那里选择了“以后再说”还是“写评价”，以免过于频繁地询问。
  • 已转卖商品列表——您在理财页面卖回的商品编号，使同一件商品无法卖两次。同一列表也会保留备份。不会离开您的设备。
  • 已开启卡片列表——从卡包中开出的卡片的编号、序列号和开启时间，用于收藏和卖回卡片。同一列表也会保留备份。不会离开您的设备。
  • 广告误触防护——几条广告点击和广告展示的时间戳，用于在短时间内反复点击时让广告暂停。不会离开您的设备（第7条）。
  • 转卖时钟——转卖价格使用的两个时间戳（见过的最新设备时间，以及转卖的“现在”），以及首次启动时的时区，“今日大奖”用它来区分每一天。这是为了防止通过修改设备时钟抬高价格，不会离开您的设备。
  • 广告设置副本——在第8条所述的版本检查中读取的广告设置（广告是否开启、使用哪些广告位），记下来以便下次启动时沿用。这是我们发给应用的值，不是从您那里获取的值，也不是个人信息。保存它是为了在没有网络时也让广告设置保持稳定。

这些值存在是为了重新绘制您的页面，而不是为了识别您。删除应用就会一并删除（第11条）。

请注意，如果您在收货地址栏中输入真实姓名和地址，它也会接受。即使如此也不会离开您的设备，而且不填这些应用也能正常运行——您可以随意输入任何内容。

3. 支付与配送——本应用最重要的告知

Faux Haul 中的购买、支付和配送完全是模拟的。

  • 购买商品不花钱。“支付”只会改变应用内的数字。购买商品背后没有接入任何真实支付。
  • 有应用内购买。在应用内购买商品仍然不花钱，但我们另外销售以下项目。支付只通过商店（App Store・Google Play）进行，我们从不会收到银行卡号或其他支付信息。不购买任何东西，也能使用应用的所有功能。
    • 底部横幅移除 + 余额赠送——一次性购买。页面底部的横幅会消失，并获得一次性的虚拟余额。这不是“去除广告”——支付等待页面上的矩形广告、转卖后的全屏广告，以及“看广告”的激励视频，在购买后仍会保留（第7条）。
    • 三种余额补充——只会增加虚拟余额，可以任意多次购买。
    • VIP 订阅（包月・包年）——自动续订的订阅。订阅期间您每天都会获得虚拟余额。除非在周期结束前至少24小时取消，否则会以相同价格自动续订；您可以随时在商店的订阅设置中取消（iPhone・iPad：设置 → Apple ID → 订阅）。扣款和续订由商店处理，我们从不会收到支付信息。
  • 恢复购买与退款。如果您更换设备或重新安装，在尊享页面点击“恢复购买”，即可找回底部横幅移除的购买和 VIP 订阅。退款由商店处理，而不是由我们处理——请使用 App Store 或 Google Play 的退款流程。只有商店能查询、取消或退还付款——我们无权取消或退还商店中的购买。
  • 转卖也是模拟的。在理财页面把商品卖回会增加您的虚拟余额。这不是真钱，无法提现，也无法转让给任何人。
  • 卡包也是虚拟的。卡包只能用虚拟余额购买，开出哪张卡是随机的。各稀有度的概率完整列在卡包页面的“查看概率”中。卡片只能卖回换取虚拟余额，无法提现，也无法转让给任何人。
  • 我们不收集银行卡号。支付页面的卡号栏是只接受前8位数字的道具；其余8位在页面上固定显示为 **** ****。您输入的内容不会被保存、不会被验证，也不会发送到任何地方，离开该页面的瞬间就会消失。
  • 我们不接触支付服务。Naver Pay、Kakao Pay、Toss 和银行转账只是可以选择的标签，仅此而已；应用没有连接其中任何一项服务。
  • 不会寄送任何东西。配送状态和“已送达”时间是应用在您的设备上计算的，没有连接任何快递公司。您输入的地址只用于显示回给您看。
  • 品牌和商品都是虚构的。它们不是真实的商标或商品，价格也与真实价格无关。

4. 照片——只用于您的头像

只有在您于 MY 页面设置头像时，我们才会请求访问您的相册。应用从不会打开相机。

  • 只有您选择的那一张照片会被复制到应用专用文件夹。我们不会读取或扫描您的相册。
  • 副本留在您的设备上。不会上传到我们的服务器——我们没有接收它的服务器。
  • 我们不分析图片、不进行人脸识别，也不读取附在图片上的位置等元数据。
  • 您可以拒绝并继续使用应用。没有照片时，会改为显示应用的标志。

5. 通知——完全在您的设备上创建

当您下虚拟订单时，会在您的设备上预约三条配送通知（下单1小时后、6小时后，以及第二天）。

  • 它们是本地通知，因此没有推送令牌。不是我们发送的；是您的设备在预约时间自行弹出。
  • 因此，您订购了什么不会离开您的设备。
  • 您可以拒绝，仍能使用所有功能。每次打开应用都能在页面上看到配送状态。

7. 广告

应用含有广告，以便保持免费（在 iPhone、iPad 和 Android 上）。

  • 广告只出现在四个地方——页面底部的横幅、模拟结账时“正在处理支付”等待页面上的矩形广告、只有在您自己点击“看广告”时才会播放的激励视频，以及在理财页面完成转卖或在卡包中“全部卖出”后立即出现的一则全屏广告。这则广告只会在交易已保存之后出现，关闭后会回到原来的位置。商品列表之间没有广告。
  • 激励广告是补充余额的一种选择——它只有在您点击时才会播放，用于增加第2条所述的虚拟金额。不看也能使用每个页面和功能，而且您的余额每天午夜都会自动补充。它也每天限三次。
  • 广告网络——广告通过 Unity 的 LevelPlay（原 ironSource）投放。由 LevelPlay 聚合的其他广告网络也可能一同投放。
  • 会读取什么——广告网络会读取您设备的广告标识符（iOS 为 IDFA/IDFV，Android 为 Android 广告 ID）、大致的国家和语言、设备型号和操作系统版本，以及应用版本。在 Android 上，广告网络还可能使用您设备上已安装的应用列表来选择广告。广告网络直接从您的设备读取这些信息；我们既不接收也不保存。
  • 不会发送什么——第2条中的任何值（心愿单、购物袋、订单记录、地址、搜索、昵称、头像）都不会传给广告网络。没有任何代码会把它们附加到广告请求中。
  • iOS 跟踪授权——首次打开应用时，会出现一次 Apple 的App 跟踪透明度提示。拒绝后应用的所有功能仍然可用；您只会看到非个性化广告。
  • 关闭个性化广告——iOS 为设置 → 隐私与安全性 → 跟踪；Android 为设置 → Google → 广告 →“删除广告 ID”。
  • 没有任何功能需要看广告才能使用。没有必须看广告才能打开的页面，无论广告是否加载应用都会继续，而且即使广告加载失败，您的余额也会补充。

广告网络自身对数据的处理受其政策约束——Unity/LevelPlay 隐私政策。

8. 应用向互联网发出的每一个请求

为了透明，以下是完整列表。

  • 版本检查——启动时应用会读取一次一个小文件，说明已安装的版本是否仍可使用。这是为了在紧急修复后能停用旧版本。不会发送任何东西——只读取文件，您的任何值都不会附带其中。如果没有连接或响应格式不正确，应用会放行而不是拦截。
    同一个文件还带有广告设置，让我们无需发布新版本就能紧急关闭广告。这同样只是读取，读回的内容会作为第2条的“广告设置副本”保存在您的设备上。
  • 打开本政策页面——在应用中点击“隐私政策”会在浏览器中打开本页面（GitHub Pages）。就像您打开任何网页一样，GitHub 的服务器日志可能会记录您的 IP 地址。
  • 给我们发消息——在 MY 标签页点击“意见反馈”会显示我们的电子邮箱地址，点击该地址会打开您设备的邮件应用，只填好收件人（如果没有邮件应用，则会改为复制该地址）。应用本身不会发送任何东西；是否发送由您在邮件应用中决定。您发来的内容我们只用于回复您。
  • 广告请求——会向广告网络发出请求以获取广告（第7条）。应用为您记录的任何内容都不会附带其中。
  • 应用内购买——当应用启动或回到前台，以及您打开购买页面或点击“恢复购买”时，应用会与商店（App Store・Google Play）通信，以获取商品列表和价格、处理未完成的购买、确认 VIP 订阅是否有效，以及确认购买结果。这项往来在商店与您的设备之间进行，我们不在其中——银行卡号或其他支付信息都不会到达我们这里（第3条）。
  • 一行销售通知（仅限 Android 版）——在 Android 上应用内购买成功时，会有一行“刚卖出一件商品”发送到我们的通知端点。其中只包含应用名称、商品编号、商店显示的价格，以及商店分配的订单号。不含任何能识别您的信息，也不含第2条中的任何值。失败时不会重试，您的购买照常进行。在 iPhone 和 iPad 上完全不会发出这个请求（改由 Apple 直接通知我们）。

除了那一行销售通知之外，没有任何请求会到达我们这里。那一行只在 Android 版的应用内购买时发出，不含任何能识别您的信息，而且我们没有任何可供积累数据的账号或个人资料。所有商品及其图片都内置在应用中，因此购物、转卖等功能在没有网络连接时也能运行（应用内购买和广告需要联网）。

9. 共享、受托处理方与数据出售

没有。由于我们不收集个人信息，没有任何东西可以共享给第三方或交给受托处理方。我们不出售任何信息。

广告网络（Unity/LevelPlay 及其聚合的网络）会直接从您的设备读取广告标识符。那不是我们接收后再转交的东西，我们也不会保留。

10. 跨境传输

我们自己不会将任何东西传输到境外。不过，广告网络直接从您的设备读取的值（广告标识符以及第7条所列的其他项目）会发送到该公司位于境外的服务器。

接收方国家项目目的保存期限
Unity Technologies（LevelPlay / ironSource）及其聚合的广告网络 美国及其服务器所在的其他国家 广告标识符、设备／操作系统／应用版本、大致的国家和语言 投放广告和衡量效果 依该公司的政策

如果您不希望进行此传输，可以按第7条的路径重置或屏蔽广告标识符。

11. 保存与删除

由于我们不持有任何东西，没有可以发送删除请求的对象。您设备上的值（第2条）可由您自行清除。

  • 在应用内——心愿单和最近浏览可用各页面右上角的“全部清除”清除，最近搜索在搜索页面清除，购物袋用“编辑 → 删除”清除。
  • 删除应用会连同头像一起清除第2条中的一切。订单记录、收货地址和昵称在应用内没有清除按钮；它们会随应用一起删除。
  • 在 Android 上，设置 → 应用 → Faux Haul → 存储 → 清除数据也能重置。

12. 儿童

Faux Haul 并非面向未满14岁的儿童，我们也不会在知情的情况下收集儿童的个人信息——我们不向任何人收集个人信息。

在应用内购买商品不花钱（第3条）。不过，应用确实有应用内购买——移除底部横幅、补充余额，以及 VIP 订阅。支付通过商店的支付方式进行，监护人可以事先在设备上屏蔽——iPhone 和 iPad 在设置 → 屏幕使用时间 → 内容和隐私访问限制 → App 内购买项目，Android 在Play 商店 → 设置 → 身份验证 → 购买时需要进行身份验证。

13. 您的权利

根据您所在的地区，您可能有权访问、更正、删除或限制处理您的个人信息（例如依据 GDPR、CCPA/CPRA 或韩国《个人信息保护法》）。由于我们不持有您的任何个人信息，这类请求没有可作用的对象。保存在您设备上的值，您随时可以按第11条自行清除。

如有任何问题，请发送邮件至 contact@nemofactory.co.kr。

14. 安全措施

  • 我们不运营任何保存您数据的服务器。没有保存关于您的任何东西，就没有东西会泄露。
  • 设备上的值存放在应用的专用存储空间中，其他应用无法读取。
  • 应用中没有任何代码会把您的活动发送到任何地方。
  • 没有任何收集银行卡号的代码。模拟支付页面上的数字既不保存也不发送。唯一涉及真钱的是应用内购买，而该支付由商店处理——应用没有接收支付信息的页面，也没有处理它的代码（第3条）。
  • 不含任何分析 SDK。除广告 SDK 外，应用中没有任何东西会收集使用数据。

15. 本政策的变更

如本政策发生变更，我们将更新本页面上的生效日期。修订后的政策自发布于本页面之日起生效。
