Deep Galaxy ကိုယ်ရေးအချက်အလက်ဆိုင်ရာ မူဝါဒ

အသက်ဝင်သည့်နေ့: 2026 ခုနှစ် နိုဝင်ဘာ 28 ရက်
ဆက်သွယ်ရန်: contact@nemofactory.co.kr

1. ကျွန်ုပ်တို့ စုဆောင်းသော ကိုယ်ရေးအချက်အလက်

Deep Galaxy ကို ကိုရီးယားနိုင်ငံရှိ Nemo factory (네모팩토리) က လည်ပတ်ပြီး ကိုယ်စားလှယ်နှင့် ကိုယ်ရေးအချက်အလက်ဆက်သွယ်သူမှာ Yang Seongmin (양성민) ဖြစ်သည်။ အကောင့်၊ ဝင်ရောက်မှု၊ သီးခြားအသုံးပြုမှုခွဲခြမ်းစိတ်ဖြာစနစ် မရှိပါ။ Android ဝယ်ယူမှုအသိပေးချက်နှင့် တောင်းဆိုမှုမှတ်တမ်း (5)၊ ဆက်သွယ်သည့် အီးမေးလ်၊ စာနှင့် ပူးတွဲဖိုင်တို့ကို စီမံသည်။ ကြော်ငြာ SDK များက အမှတ်အသား၊ စက်အချက်အလက်၊ ခန့်မှန်းတည်နေရာ၊ ကြော်ငြာတုံ့ပြန်မှုနှင့် စစ်ဆေးချက်များ ယူသည် (4)။ ကတ်နံပါတ်၊ စကားဝှက် မယူပါ။

2. သင့်စက်ပေါ်တွင်သာ သိမ်းဆည်းသည့်အရာ

စက်တွင်း၌ ဘာသာစကား၊ သီချင်း၊ မြင်ကွင်း၊ ယာဉ်၊ Pro၊ သဘောတူမှု၊ အလွဲသုံးမှုကာကွယ်ရေး၊ အဝေးမှဆက်တင်၊ ပထမဖွင့်ချိန်၊ လမ်းညွှန်၊ ဖွင့်သည့်နေ့၊ သွားခဲ့သော ကြယ်တာရာ ID နှင့် အမှတ်ပေးတောင်းသည့်ဗားရှင်း သိမ်းသည်။ ဤအသုံးပြုမှုမှတ်တမ်းကို ကျွန်ုပ်တို့ဆာဗာသို့ မပို့ပါ။ Android Settings → Apps → Deep Galaxy → Storage → Clear data ဖြင့် ဖျက်နိုင်သည်။ အက်ပ်ဖယ်ရှားလျှင် စက်တွင်းဒေတာပျက်သော်လည်း OS backup က ဆက်တင်ပြန်ရနိုင်သည်။ စတိုးဝယ်ယူမှုမှတ်တမ်းက သီးခြားဖြစ်သည်။

3. ခွင့်ပြုချက်များ

ခွင့်ပြုချက်ဘာကြောင့် လိုအပ်သနည်း
ခြေရာခံခွင့် (ရွေးချယ်နိုင်၊ iPhone ATT)စိတ်ကြိုက်ကြော်ငြာများအတွက် ကြော်ငြာ ID (IDFA) ကို အသုံးပြုရန် (အပိုင်း 4)။ ငြင်းပယ်လျှင်လည်း အက်ပ်တစ်ခုလုံး ယခင်အတိုင်း အလုပ်လုပ်ပြီး စိတ်ကြိုက်ကြော်ငြာအစား ယေဘုယျကြော်ငြာများ ပြပါမည်
Advertising ID (Android၊ ထည့်သွင်းချိန်တွင် ခွင့်ပြုပြီး)ကြော်ငြာကွန်ရက်များက စက်၏ Advertising ID ကို ဖတ်၍ ကြော်ငြာပြရန်နှင့် စွမ်းဆောင်ရည် တိုင်းတာရန် (အပိုင်း 4)။ မည်သည့် တောင်းဆိုချက်မျှ မပေါ်ပါ။ စက်၏ ဆက်တင်တွင် အချိန်မရွေး ပြန်လည်သတ်မှတ်နိုင် သို့မဟုတ် ဖျက်နိုင်ပါသည် (အပိုင်း 4)
အင်တာနက်နှင့် ကွန်ရက် အခြေအနေ (ထည့်သွင်းချိန်တွင် ခွင့်ပြုပြီး)အက်ပ်အခြေအနေဖိုင်၊ ကြော်ငြာနှင့် စတိုး ငွေပေးချေမှုတို့နှင့် ချိတ်ဆက်ရန် (အပိုင်း 5)

အက်ပ်သည် ကင်မရာ၊ မိုက်ခရိုဖုန်း၊ ဓာတ်ပုံ၊ တည်နေရာ၊ အဆက်အသွယ်များ၊ ပြက္ခဒိန် သို့မဟုတ် ကျန်းမာရေးအချက်အလက်ကို မဝင်ရောက်ဘဲ ထိုခွင့်ပြုချက်များကိုလည်း မတောင်းပါ။

4. ကြော်ငြာနှင့် ငွေပေးချေမှု

  • ကြော်ငြာသည် နေရာတစ်ခုတည်းတွင်သာ ရှိပါသည် — အခမဲ့ နေရာ (နေ၊ ဗုဒ္ဓဟူးဂြိုဟ်၊ သောကြာဂြိုဟ်၊ ကမ္ဘာ၊ လ၊ အင်္ဂါဂြိုဟ်၊ ကြာသပတေးဂြိုဟ်နှင့် ကြာသပတေး၏ လများ) သို့ သွားစဉ် "ကြော်ငြာကြည့်ပြီး သွားရန်" ကို သင်ကိုယ်တိုင် ရွေးမှသာ ပြသသော ဆုလာဘ် ဗီဒီယိုကြော်ငြာ ဖြစ်ပါသည်။ အဆုံးထိ ကြည့်လျှင် ထိုနေရာသို့ ရောက်ပါမည်။ အက်ပ်ဖွင့်ချိန် သို့မဟုတ် စခရင်ပြောင်းချိန်တွင် အလိုအလျောက် ပေါ်လာသော ကြော်ငြာ သို့မဟုတ် ဘဏ်နာကြော်ငြာ မရှိပါ။
  • ကြော်ငြာကွန်ရက် — ကြော်ငြာများကို Unity ၏ LevelPlay (ယခင် ironSource) မှတစ်ဆင့် ပြသပြီး ကြော်ငြာ မိတ်ဖက်များမှာ Unity Ads, Liftoff နှင့် Meta Audience Network ဖြစ်ပါသည်။
  • ဖတ်ယူသည့်အရာ — ကြော်ငြာ ID (IDFA၊ IDFV / Android Advertising ID၊ App Set ID)၊ စက်၊ OS၊ အက်ပ်ဗားရှင်း၊ ဘာသာစကား စသည့် စက်အချက်အလက်၊ ချိတ်ဆက်ထားသော IP မှ ခန့်မှန်းသည့် နိုင်ငံနှင့် မြို့၊ ကြော်ငြာ ကြည့်ခြင်း/နှိပ်ခြင်း မှတ်တမ်း၊ ကြော်ငြာကုဒ်၏ လုပ်ဆောင်မှု မှတ်တမ်း။ ဤတန်ဖိုးများကို ကြော်ငြာကွန်ရက်များက သင့်စက်မှ တိုက်ရိုက် ဖတ်ယူပြီး ကျွန်ုပ်တို့ မလက်ခံ၊ မသိမ်းဆည်းပါ။
  • ထည့်သွင်းထားသော အက်ပ်များ (Android) — ကြော်ငြာတစ်ခုကြောင့် ထည့်သွင်းမှု ဖြစ်ခဲ့သလား ရေတွက်ရန်နှင့် သင့်ထံ ရှိပြီးသား အက်ပ်များအတွက် ကြော်ငြာ မပြမိစေရန် ကြော်ငြာပံ့ပိုးသူများ၏ ကုဒ်သည် စက်ပစ္စည်းပေါ်တွင် မည်သည့်အက်ပ်များ ထည့်သွင်းထားသည်ကို စစ်ဆေးနိုင်ပါသည်။
  • ခြေရာခံခြင်း သဘောတူညီချက် — Space Pro မဝယ်ရသေးသော အသုံးပြုသူက အက်ပ်ကို ပထမဆုံးအကြိမ် ဖွင့်သည့်အခါ Apple ၏ ခြေရာခံခွင့် တောင်းဆိုချက် (ATT) တစ်ကြိမ် ပေါ်လာပါမည်။ ခွင့်မပြုပါက စိတ်ကြိုက်မဟုတ်သော ကြော်ငြာများ ပြပြီး လုပ်ဆောင်ချက်အားလုံးကို ဆက်သုံးနိုင်ပါသည်။ ခွင့်ပြုမပြုကို Settings → Privacy & Security → Tracking တွင် အချိန်မရွေး ပြောင်းနိုင်ပါသည်။
  • Android Advertising ID ကို ပိတ်ခြင်း — Android တွင် ခြေရာခံခွင့် တောင်းဆိုချက် မရှိပါ။ စိတ်ကြိုက်ကြော်ငြာ မလိုလားပါက Settings → Privacy → Ads (စက်အချို့တွင် Settings → Google → Ads) သို့ သွား၍ သင့် Advertising ID ကို ဖျက်နိုင် သို့မဟုတ် ပြန်လည်သတ်မှတ်နိုင်ပါသည်။ ဖျက်ပြီးနောက် ကြော်ငြာကွန်ရက်များသည် ID အစား သုညများသာ ပါသော တန်ဖိုးကိုသာ ရရှိပြီး လုပ်ဆောင်ချက်အားလုံး ဆက်လက် အလုပ်လုပ်ပါသည်။
  • Space Pro ဝယ်ပြီးနောက် — ကြော်ငြာ လုပ်ဆောင်ချက်များ (ကြော်ငြာကွန်ရက်များ၏ ကုဒ်) ကို မဖွင့်ဘဲ ခြေရာခံခွင့် တောင်းဆိုချက်ကိုလည်း မပြပါ။

ဥရောပ စီးပွားရေးဒေသ (EEA)၊ ယူကေနှင့် ဆွစ်ဇာလန်ရှိ အသုံးပြုသူများ
ဤဒေသများတွင် အထက်ပါ ကြော်ငြာ မိတ်ဖက်များ (Unity, Liftoff, Meta) က စိတ်ကြိုက်ကြော်ငြာများအတွက် သင့်စက်ကို အသုံးပြုနိုင်မလားဟု မည်သည့်ကြော်ငြာကိုမျှ မတောင်းဆိုမီ အက်ပ်အတွင်း၌ ဦးစွာ မေးပါသည်။ “ငြင်းမည်” ကို ရွေးခြင်းသည် “သဘောတူမည်” ကဲ့သို့ပင် လွယ်ကူပြီး မည်သည့်ဘက်ကို ရွေးသည်ဖြစ်စေ လုပ်ဆောင်ချက်တိုင်း အလုပ်လုပ်ကာ ကြော်ငြာများလည်း ဆက်ပေါ်ပါသည် — ငြင်းလျှင် ၎င်းတို့သည် စိတ်ကြိုက်ကြော်ငြာ မဟုတ်ရုံသာ ဖြစ်ပါသည်။ စိတ်ကြိုက်ကြော်ငြာများအတွက် သင့်သဘောတူညီချက် (GDPR ပုဒ်မ 6(1)(a)) ကို လည်းကောင်း၊ စိတ်ကြိုက်မဟုတ်သော ကြော်ငြာများ ပြသခြင်းနှင့် ကြော်ငြာ အလွဲသုံးစားမှု ကာကွယ်ရေး (အပိုင်း 2) အတွက် ကျွန်ုပ်တို့၏ တရားဝင် အကျိုးစီးပွား (ပုဒ်မ 6(1)(f)) ကို လည်းကောင်း အခြေခံပါသည်။ အက်ပ်၏ ဆက်တင် > ကြော်ငြာ ကိုယ်ရေးလုံခြုံမှု တွင် သင့်ရွေးချယ်မှုကို အချိန်မရွေး ပြောင်းလဲ သို့မဟုတ် ရုပ်သိမ်းနိုင်ပြီး နောက်ကြော်ငြာ တောင်းဆိုမှုမှစ၍ အကျိုးသက်ရောက်ပါသည်။ iPhone တွင် ခြေရာခံခွင့် တောင်းဆိုချက် (ATT) ကို ဦးစွာ ပြပြီး ခြေရာခံခြင်းကို သင်ခွင့်ပြုမှသာ ဤမေးခွန်း ဆက်ပေါ်ပါသည်။ ခွင့်မပြုပါက ဤမေးခွန်းမပါဘဲ စိတ်ကြိုက်မဟုတ်သော ကြော်ငြာများသာ ပြပါသည်။ ကြော်ငြာကွန်ရက်များသည် စံစာချုပ်အပိုဒ်များ (Standard Contractual Clauses) ကဲ့သို့ ၎င်းတို့ကိုယ်ပိုင် အကာအကွယ်များအောက်တွင် ဒေတာကို အမေရိကန်နှင့် အခြားနိုင်ငံများသို့ လွှဲပြောင်းနိုင်ပါသည်။

ကြော်ငြာကွန်ရက်များသည် ဒေတာကို ၎င်းတို့၏ မူဝါဒအတိုင်း ကိုင်တွယ်ပါသည် — Unity/LevelPlay ကိုယ်ရေးအချက်အလက်ဆိုင်ရာ မူဝါဒ · Liftoff ကိုယ်ရေးအချက်အလက်ဆိုင်ရာ မူဝါဒ · Meta ကိုယ်ရေးအချက်အလက်ဆိုင်ရာ မူဝါဒ။

Space Pro သည် တစ်ကြိမ်ဝယ်လျှင် တစ်သက်တာ သုံးနိုင်သော ဝယ်ယူမှု ဖြစ်ပါသည် (စာရင်းသွင်းမှု မဟုတ်ဘဲ ဘယ်တော့မှ သက်တမ်းမတိုးပါ)။ ငွေပေးချေမှုကို App Store နှင့် Google Play က ကိုင်တွယ်ပြီး ကတ်နံပါတ်ကဲ့သို့ ငွေပေးချေမှုအချက်အလက်ကို Apple နှင့် Google က တိုက်ရိုက် လက်ခံ၍ လုပ်ဆောင်ပါသည်။ ကျွန်ုပ်တို့ မမြင်ရ၊ မလက်ခံ၊ မသိမ်းဆည်းပါ။ ဝယ်ယူမှုကို ပြန်ယူသည့်အခါ သင်ဝယ်ထားသလားကိုသာ အက်ပ်က သင့်စက်ရှိ စတိုးနှင့် စစ်ဆေးပါသည်။ iPhone တွင် အသုံးပြုမှုစည်းကမ်းများသည် Apple ၏ စံ လိုင်စင်သဘောတူညီချက် (EULA) ကို လိုက်နာပါသည်။

5. အက်ပ်က အပြင်သို့ ပို့သော တောင်းဆိုမှုများ — အားလုံး

  • အက်ပ်အခြေအနေဖိုင် — အက်ပ်စတင်သည့်အခါ သင့်ဗားရှင်းကို မဖြစ်မနေ အပ်ဒိတ်လုပ်ရမလားနှင့် ကြော်ငြာဆက်တင် (ကြော်ငြာကို အရေးပေါ် ပိတ်ရန် လိုသည့်အခါ သုံးသော တန်ဖိုး) ကို စစ်ဆေးရန် ကျွန်ုပ်တို့ ဝဘ်ဆိုက် (Netlify တွင် လက်ခံထားသည်) ရှိ ဖိုင်ငယ်တစ်ခုကို ဖတ်ပါသည်။ ဤတောင်းဆိုမှုသည် ဖိုင်ကို ဒေါင်းလုဒ်လုပ်ရုံသာဖြစ်ပြီး သင့်အကြောင်း မည်သည့်တန်ဖိုးကိုမျှ မသယ်ဆောင်ပါ။ မည်သည့် ဝဘ်စာမျက်နှာမဆို ကဲ့သို့ပင် လက်ခံဆာဗာ မှတ်တမ်းတွင် ချိတ်ဆက်သူ၏ IP လိပ်စာ ကျန်ရှိနိုင်ပါသည်။ ချိတ်ဆက်မှု မရှိပါက စစ်ဆေးခြင်းကို ကျော်ပါသည်။
  • ကြော်ငြာ တောင်းဆိုမှု — Space Pro မဝယ်ရသေးသော အသုံးပြုသူများအတွက် အက်ပ်ဖွင့်ချိန်တွင် ကြော်ငြာကွန်ရက်နှင့် ချိတ်ဆက်ပြီး ကြော်ငြာ ရွေးနိုင်သော ဝင်းဒိုး ပွင့်လာသည့်အခါ ကြော်ငြာကို ကြိုတင် ဖွင့်ထားပါသည် (အပိုင်း 4)။ Space Pro ဝယ်ပြီးနောက် အက်ပ်သည် ကြော်ငြာကွန်ရက်နှင့် မချိတ်ဆက်တော့ပါ။
  • စတိုး ငွေပေးချေမှု — ဈေးနှုန်းပြရန်၊ ဝယ်ယူရန် သို့မဟုတ် ဝယ်ယူမှုကို ပြန်ယူရန် စက်ရှိ App Store သို့မဟုတ် Google Play နှင့် ဆက်သွယ်ပါသည်။
  • ဝယ်ယူမှု အသိပေးချက် (Android သာ) — Android တွင် ငွေပေးချေမှု ပြီးဆုံးသည့်အခိုက် ဆော့ဖ်ဝဲရေးသူထံ "တစ်ခု ရောင်းရပြီ" ဟု အသိပေးရန် ကျွန်ုပ်တို့၏ ဆာဗာ သို့ တောင်းဆိုမှု တစ်ကြိမ် ပို့ပါသည်။ ပါဝင်သည်မှာ အက်ပ်အမည်၊ ပလက်ဖောင်း၊ ထုတ်ကုန် (အမည်နှင့် ID)၊ ငွေပမာဏ၊ ငွေပေးချေသည့်အချိန်နှင့် ဝယ်ယူမှု တိုကင် (Google Play က ဤငွေပေးချေမှုတွင် တွဲပေးသော တန်ဖိုး) သာဖြစ်ပြီး အမည်၊ ဆက်သွယ်ရန်အချက်အလက် သို့မဟုတ် စက် ID မပါဝင်ပါ။ ဆာဗာက ၎င်းကို ဆော့ဖ်ဝဲရေးသူ၏ မက်ဆင်ဂျာ သို့ တစ်ကြောင်းတည်း ပို့ပေးပါသည်။ ဝယ်ယူမှု တိုကင်ကို တူညီသော အသိပေးချက် နှစ်ကြိမ် မရောက်စေရန် ခဏသာ သုံးပြီး သီးခြား မသိမ်းဆည်းပါ။ ဆာဗာမှတ်တမ်းတွင် ချိတ်ဆက်သည့် IP လိပ်စာ၏ တစ်စိတ်တစ်ပိုင်း၊ ချိတ်ဆက်သည့် ဆော့ဖ်ဝဲ အချက်အလက်နှင့် ဝယ်ယူမှု တိုကင်၏ အစပိုင်း ကျန်ရှိနိုင်ပါသည်။ iPhone တွင် ဤတောင်းဆိုမှုကို မပို့ပါ။
  • သင်ကိုယ်တိုင် နှိပ်သော လင့်ခ်များ — "သုံးသပ်ချက် ရေးရန်" (App Store သို့မဟုတ် Google Play)၊ "ကိုယ်ရေးအချက်အလက်ဆိုင်ရာ မူဝါဒ" (ဤစာမျက်နှာ၊ GitHub Pages) နှင့် "ဆက်သွယ်ရန်" (မေးလ်အက်ပ်) တို့သည် သင့်စက်ပေါ်တွင် ပွင့်ပြီး ထိုနေရာမှစ၍ ထိုဝန်ဆောင်မှု၏ ကိုယ်ပိုင် မူဝါဒ သက်ရောက်ပါသည်။

ပုံများနှင့် ကြယ်ဒေတာ အားလုံး အက်ပ်အတွင်း၌ ရှိသဖြင့် အင်တာနက် မရှိဘဲလည်း လှည့်လည်ကြည့်ရှုနိုင်ပါသည်။

6. ပြင်ပအဖွဲ့ထံ ပေးခြင်း၊ နိုင်ငံခြားသို့ လွှဲပြောင်းခြင်း၊ ရောင်းချခြင်း

ဒေတာမရောင်းပါ။ လိုအပ်သည့်ဒေတာကို အောက်ပါကြော်ငြာမိတ်ဖက်များ၊ Apple/Google (ငွေပေးမှု)၊ Render (ဝယ်ယူမှုအသိပေး)၊ Netlify (အခြေအနေ)၊ GitHub Pages (မူဝါဒ)၊ ဖန်တီးသူ၏စာပို့ဝန်ဆောင်မှုတို့က စီမံသည်။ Host က IP၊ အချိန်၊ client အချက်အလက်၊ အသိပေးဆာဗာက အပိုင်း 5 ဒေတာကို စီမံသည်။ စာတွင် ကုန်ပစ္စည်း/ငွေပမာဏပါသော်လည်း ဝယ်ယူမှု token မပါ။ စီမံချိန်၌ ပြည်ပဆာဗာသို့ ပို့နိုင်ပြီး နိုင်ငံ၊ သိမ်းချိန်သည် ပံ့ပိုးသူမူဝါဒအတိုင်းဖြစ်သည်။

လက်ခံသူအချက်များရည်ရွယ်ချက်
Unity Technologies (LevelPlay / ironSource · Unity Ads), Liftoff, Meta Platforms, Inc. (Meta Audience Network)ကြော်ငြာ ID၊ စက် / OS / အက်ပ်ဗားရှင်း၊ ခန့်မှန်း နိုင်ငံနှင့် ဘာသာစကား၊ ကြော်ငြာ အပြန်အလှန်ဆက်ဆံမှု၊ ထည့်သွင်းထားသော အက်ပ်များ (Android)ကြော်ငြာ ပြသခြင်း၊ စွမ်းဆောင်ရည် တိုင်းတာခြင်းနှင့် ကြော်ငြာ လိမ်လည်မှု ကာကွယ်ခြင်း

မလိုလားပါက iPhone တွင် ခြေရာခံခွင့်ကို ပိတ်၍ သို့မဟုတ် Android တွင် Advertising ID ကို ဖျက်၍ ကြော်ငြာ ID ပေးခြင်းကို တားဆီးနိုင်ပါသည် (အပိုင်း 4)။

7. သိမ်းဆည်းကာလနှင့် ဖျက်ခြင်း

စက်တွင်းဒေတာကို ဖျက်သည်အထိ၊ အီးမေးလ်ကို ပြန်ဖြေဖြေရှင်းရန် လိုအပ်သည်အထိထားပြီး ဖျက်သည်။ ထပ်နေမှုတား token များကို ဆာဗာ memory တွင်သာ အများဆုံး 500 သိမ်းပြီး အဟောင်းများဖယ်ရှားခြင်း သို့မဟုတ် restart ဖြင့် ပျောက်သည်။ ယင်းက လည်ပတ်ရေး/လုံခြုံရေးနှင့် ဝယ်ယူမှုစစ်ဆေးရေး/ပံ့ပိုးရေးအတွက် လိုအပ်သည့် log သို့မဟုတ် စာများကို မဖျက်ပါ။ ပံ့ပိုးသူစည်းမျဉ်းနှင့် ဥပဒေသိမ်းချိန်လည်း သက်ဆိုင်သည်။ ကျွန်ုပ်တို့ဒေတာဖျက်ရန် အီးမေးလ်ပို့ပါ။ ကြော်ငြာ ID ပြန်သတ်မှတ်ခြင်း၊ အက်ပ်ဖယ်ရှားခြင်း၊ Pro ဝယ်ခြင်းက ပို့ပြီးဒေတာမဖျက်ပါ။ ကြော်ငြာဒေတာဖျက်ရန် မိတ်ဖက်ထံတောင်းပါ၊ လမ်းညွှန်နိုင်သည်။ အခြေအနေနှင့် ဝယ်ယူမှုအသိပေးချက်သည် HTTPS သုံးသည်။

သင်သည် ဥရောပ စီးပွားရေးဒေသ၊ ယူနိုက်တက်ကင်းဒမ်း သို့မဟုတ် ဆွစ်ဇာလန်တွင် ရှိနေပါက ဤအပိုင်း သက်ဆိုင်ပါသည်။ ၎င်းသည် အထက်ပါ အပိုင်းများကို ဖြည့်စွက်ပါသည်။

  • တာဝန်ရှိသူ — ကျွန်ုပ်တို့ကိုယ်တိုင် စီမံဆောင်ရွက်သည့် အနည်းငယ်သော ဒေတာအတွက် ဤအက်ပ်၏ ဆော့ဖ်ဝဲရေးသူ (ကိုရီးယား သမ္မတနိုင်ငံ) သည် ဒေတာထိန်းချုပ်သူ (controller) ဖြစ်ပါသည်။ ဆက်သွယ်ရန်: contact@nemofactory.co.kr။ ကိုရီးယား သမ္မတနိုင်ငံသည် ဥရောပကော်မရှင်နှင့် ယူနိုက်တက်ကင်းဒမ်း၏ လုံလောက်မှု ဆုံးဖြတ်ချက်များ (adequacy decisions) တွင် ပါဝင်ပါသည်။

  • ကြော်ငြာများ — စိတ်ကြိုက်ကြော်ငြာများကို သင့်သဘောတူညီချက်ဖြင့်သာ ပြသပါသည် (ပုဒ်မ 6(1)(a))။ စိတ်ကြိုက်မဟုတ်သော ကြော်ငြာများနှင့် ကြော်ငြာ လိမ်လည်မှုမှ ကာကွယ်ခြင်းသည် ကျွန်ုပ်တို့၏ တရားဝင် အကျိုးစီးပွား (ပုဒ်မ 6(1)(f)) ကို အခြေခံပါသည်။ အထက်တွင် ဖော်ပြထားသော ကြော်ငြာကွန်ရက်များသည် ဤဒေတာကို ၎င်းတို့၏ ကိုယ်ပိုင် မူဝါဒများအရ လွတ်လပ်သော ထိန်းချုပ်သူများအဖြစ် စီမံဆောင်ရွက်ပါသည်။ အထက်တွင် ဖော်ပြထားသော အက်ပ်ဆက်တင်ရှိ ကြော်ငြာ ကိုယ်ရေးလုံခြုံမှု ရွေးချယ်စရာဖြင့် သင့်သဘောတူညီချက်ကို အချိန်မရွေး ရုပ်သိမ်းနိုင်ပါသည်။ ရုပ်သိမ်းခြင်းသည် ယင်းမတိုင်မီ စီမံဆောင်ရွက်ခဲ့မှုကို မထိခိုက်ပါ။
