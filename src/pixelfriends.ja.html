PixelFriends プライバシーポリシー

施行日: 2026年10月2日
お問い合わせ: contact@nemofactory.co.kr

ひとことで
PixelFriends には会員登録もログインもなく、私たちはサーバーを運用していません。選んだペット、レベル、設定は端末の中にとどまり、私たちに送られることはありません。アプリを無料で提供するため、広告を含んでいます。広告ネットワークは端末の広告識別子を読み取ります。何を読み取るのか、どうすればオフにできるのかは第4項に記載しています。アクセス解析は一切ありません。

1. 収集する情報

一切収集しません。氏名、連絡先、メールアドレス、位置情報、写真その他の個人情報が私たちに届くことはありません。アカウント機能もありません。

ただし、広告ネットワークは広告を表示するために、広告識別子と一般的な端末情報を端末から直接読み取ります（第4項）。私たちがその値を受け取ったり保管したりすることはありません。

例外がひとつあります。設定画面の一番下にあるお問い合わせ・報告をタップすると、端末のメールアプリが開きます。お書きになった内容と返信先アドレス（入力された場合）は、そのメールに載って私たちに届きます。送信するのはお使いのメールアプリです。アプリ自体は何も収集せず、私たちのサーバーにも何も送りません。

2. 端末にだけ保存される情報

以下はアプリ専用の保存領域に保管され、端末の外に出ることはありません。

  • ペットの設定 — 選んだペット、そのスタイル、ダイナミックアイランドのどちら側にいるか、出しっぱなしにするかどうか、最後に表示した時刻。
  • レベル — 各ペットがダイナミックアイランドにいた時間と、あげたおやつ。
  • テーマと言語 — 選んだテーマと言語（選んでいない場合は端末の言語を使います）。
  • 自動キープの設定 — 8時間ごとにペットをダイナミックアイランドに戻すかどうか。
  • ごはんの記録 — 無料のごはん（おにぎり、お魚、お肉）を最後にあげた時刻。次にあげられるまでの待ち時間を数えるために使います。
  • はらぺこ通知の設定 — 無料のおにぎりがまた用意できたときにお知らせするかどうか。
  • 広告の不正防止 — 広告のタップと表示の時刻をいくつか。広告が繰り返しタップされたときに、しばらく広告を止めるためのものです（第4項）。
  • 広告設定の控え — 第5項の「バージョン確認」で読み込んだ広告設定（広告がオンかどうかなど）を、次回の起動用に保管したもの。これは私たちがアプリに送る値であり、利用者から取得した値ではありません。

レベルを数えるため、アプリは端末が電源を入れてから動作している時間（システム稼働時間）を読み取ります。これにより、時計を変更しても時間を水増しできません。この値は端末の中でのみ使われます。

これらはいずれも利用者個人を特定するものではありません。アプリを削除すると、すべて削除されます。

3. 権限

権限理由
ライブアクティビティ ダイナミックアイランドとロック画面にペットを表示するためです。アプリの中核となる機能です
通知（任意） ペットが眠ったとき（ダイナミックアイランドから消えたとき）とおなかが空いたとき（無料のおにぎりが用意できたとき）にお知らせし、システムによって消されたペットを呼び戻すためです。許可しなくてもアプリは使えます
トラッキング（任意、ATT） パーソナライズ広告のために広告識別子（IDFA）を使うためです（第4項）。許可しない場合はパーソナライズされていない広告が表示され、アプリ全体は同じように動作します

アプリは位置情報、連絡先、写真、カメラ、マイク、ヘルスケアデータにアクセスせず、それらの権限を求めることもありません。

4. 広告と決済

アプリを無料で提供するため、広告を含んでいます。

  • 広告が出るのは2か所だけです — 成長タブで「お魚」をタップしたときに開く釣りの画面の四角い広告（4秒後に自動で閉じ、お魚がもらえます）と、「お肉」をタップしたときだけ再生されるリワード動画です。起動時や画面の切り替え時に出る広告も、画面下部のバナーもありません。
  • 広告を見ないと使えない機能はありません。お魚とお肉はレベルの時間を増やすための任意の手段で、それらを使わなくてもすべての画面と機能を利用できます。広告の読み込みに失敗しても、ごはんはもらえます。
  • 広告ネットワーク — 広告は Unity の LevelPlay（旧 ironSource）を通じて配信され、LevelPlay は他の広告ネットワーク（Unity Ads、Liftoff など）を仲介することがあります。
  • 読み取るもの — 広告ネットワークは端末の広告識別子（IDFA/IDFV）、おおよその国と言語、端末の機種、OS のバージョン、アプリのバージョンを読み取ります。これらは端末から直接読み取られ、私たちが受け取ったり保管したりすることはありません。
  • 送られないもの — 第2項の値（ペット、レベル、設定、ごはんの記録）が広告ネットワークに渡ることはありません。アプリにはそれらを広告リクエストに含めるコードがありません。
  • トラッキングの同意 — 初めてアプリを開いたとき、Apple の App Tracking Transparency の確認画面が一度だけ表示されます。許可しなくてもすべての機能を使え、代わりにパーソナライズされていない広告が表示されます。この設定は設定 → プライバシーとセキュリティ → トラッキングでいつでも変更できます。
  • サブスクリプション中も広告は残ります。どちらの場所も、タップしたときにだけ広告が出るため、サブスクリプション（ぜんぶ開ける）は広告を消すための商品ではありません。

広告ネットワークは各社のポリシーに従ってデータを取り扱います — Unity/LevelPlay プライバシーポリシー。

決済は App Store が処理します。アプリ内で販売するもの（ペットパック、ぜんぶ開ける、おやつ、サブスクリプション）はすべて App Store で支払われます。カード情報は直接 Apple に送られ、私たちが見たり、受け取ったり、保管したりすることはありません。アプリが知るのは、購入されたかどうかと、ストアが提供する価格の表示だけです。

サブスクリプションは、期間終了の24時間前までに解約しない限り同じ期間で自動更新され、Apple アカウントに請求されます。設定 → Apple アカウント → サブスクリプションでいつでも解約できます。利用条件は Apple の標準使用許諾契約（Licensed Application End User License Agreement）に従います。

5. アプリが外部に送るすべてのリクエスト

  • ペットの表示: ありません。端末の中だけで、オフラインで動作します。
  • バージョン確認: 起動時に一度、このバージョンがまだ使えるかどうかを示す小さなファイルを読み込みます。同じファイルには広告設定も入っています（新しいリリースなしで広告をすばやくオフにできるようにするためです）。読み込むだけで、利用者のデータは一切含みません。インターネットに接続していない場合、アプリはそのまま動作を続けます。
  • 広告リクエスト: 広告を取得するために広告ネットワークへリクエストが送られます（第4項）。アプリが記録したものは何も含まれません。
  • App Store での購入: 価格の表示と購入のために、アプリは端末上で App Store とやり取りします。私たちのサーバーは関与しません。
  • このページを開くとき: お使いのブラウザがこのページ（GitHub Pages）を開きます。一般的なウェブページと同様に、GitHub が IP アドレスを記録することがあります。

6. 第三者提供、処理の委託、国外移転、販売

私たちは何も共有、移転、販売しません。決済は Apple が自社のポリシーに従って処理します。

ただし、広告ネットワークが端末から直接読み取る値（広告識別子など、第4項）は、国外にあるそれらの会社のサーバーに送られます。

受け取る者項目目的
Unity Technologies（LevelPlay / ironSource）および仲介される広告ネットワーク 広告識別子、端末 / OS / アプリのバージョン、おおよその国と言語 広告の表示と効果の測定

これを止めるには、トラッキングをオフにして（第3項）広告識別子が提供されないようにしてください。

7. 保管と削除

私たちは利用者のデータを保有していないため、私たちが消去するものはありません。広告ネットワークが読み取った値は、各社のポリシーに従って保管・削除されます。端末内のデータはアプリを削除すると消去されます。お問い合わせ・報告からお送りいただいたメールは、返信と問題の解決に必要な間だけ保管し、その後削除します。

8. 子ども

PixelFriends を通じて個人情報を収集することはなく、子どもから故意に情報を収集することもありません。トラッキングがオフの場合（第3項）、広告識別子はパーソナライズ広告に使われません。

9. 利用者の権利

利用者は、ご自身の個人情報の開示、訂正、削除、処理の停止を求めることができます。私たちは個人情報を保有していないため、請求の対象となるものはありません。端末内のデータは、第7項のとおりいつでも削除できます。

10. 変更

本ポリシーを変更する場合は、このページの施行日を更新します。
