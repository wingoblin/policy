1. 수집하는 개인정보

Deep Galaxy의 운영자는 대한민국 네모팩토리(Nemo factory), 대표자·개인정보 보호책임자는 양성민입니다. 계정·로그인과 별도의 이용 분석 도구는 없습니다. Android 결제 알림·접속 기록(5항)과 문의하실 때 보내신 이메일 주소·본문·첨부파일을 처리합니다. 광고 SDK도 광고 식별자·기기 정보·대략적 위치·광고 상호작용·진단 정보를 수집·이용합니다(4항). 카드번호나 비밀번호는 받지 않습니다.

2. 기기에만 저장되는 것

언어·음악·둘러보기 모드·탈것 설정, Pro 구입 상태, 광고 동의·오작동 방지·원격 설정, 첫 실행 시각·안내 표시 여부, 평점 요청용 실행일·방문 천체 ID·요청한 앱 버전을 기기에 저장합니다. 이 이용 기록을 저희 서버로 전송하지 않습니다. Android 설정 → 앱 → Deep Galaxy → 저장공간 → 데이터 삭제에서 지울 수 있습니다. 앱 삭제 시 로컬 데이터도 삭제되지만 OS 백업 복원으로 일부 설정이 돌아올 수 있습니다. 스토어 구매 내역은 별도로 유지됩니다.

3. 앱 접근권한

권한왜 필요한가
추적 허용(선택, iPhone ATT)맞춤 광고를 위해 광고 식별자(IDFA)를 쓰려고(4항). 거절하셔도 앱은 전부 그대로 동작하며, 맞춤 광고 대신 일반 광고가 나옵니다
광고 ID(Android, 설치 시 자동 허용)광고 네트워크가 기기의 광고 ID 를 읽어 광고를 보여 주고 성과를 재려고(4항). 묻는 창은 따로 뜨지 않으며, 기기 설정에서 언제든 재설정하거나 삭제하실 수 있습니다(4항)
인터넷·네트워크 상태(설치 시 자동 허용)앱 상태 파일·광고·스토어 결제와 통신하려고(5항)

카메라·마이크·사진·위치·연락처·캘린더·건강 정보에는 접근하지 않으며, 해당 권한을 요청하지 않습니다.

4. 광고 · 결제

  • 광고는 한 자리뿐입니다 — 무료 천체(해·수성·금성·지구·달·화성·목성과 목성의 위성)를 보러 갈 때 「광고 보고 보기」를 직접 고르셨을 때만 재생되는 보상형 동영상 광고입니다. 끝까지 보시면 그 천체로 갑니다. 앱을 켜거나 화면을 넘길 때 저절로 뜨는 광고, 띠 배너는 없습니다.
  • 광고 네트워크 — Unity 의 LevelPlay(구 ironSource) 를 통해 광고가 표시되며, 광고 파트너는 Unity Ads, Liftoff 와 Meta Audience Network 입니다.
  • 읽어 가는 것 — 광고 식별자(IDFA·IDFV / Android 광고 ID·앱 세트 ID), 기기·OS·앱 버전·언어 같은 기기 정보, 접속 IP 로 짐작한 대략적인 국가·도시, 광고를 본·누른 기록, 광고 코드의 동작 기록. 이 값은 광고 네트워크가 이용자의 기기에서 직접 읽어 가며, 저희는 받지도 보관하지도 않습니다.
  • 설치된 앱 정보(Android) — 광고 사업자의 코드가 기기에 어떤 앱이 설치되어 있는지 확인할 수 있습니다. 광고를 보고 설치했는지 세거나, 이미 설치한 앱의 광고를 다시 띄우지 않는 데 쓰입니다.
  • 추적 동의 — 우주 Pro 를 사지 않은 이용자가 앱을 처음 켤 때 애플의 추적 허용 요청(ATT) 창이 한 번 뜹니다. 허용하지 않으시면 맞춤이 아닌 광고가 나오며, 모든 기능을 그대로 쓰실 수 있습니다. 허용 여부는 설정 → 개인정보 보호 및 보안 → 추적 에서 언제든 바꾸실 수 있습니다.
  • Android 광고 ID 끄기 — Android 에는 추적 허용 창이 없습니다. 맞춤 광고를 원하지 않으시면 설정 → 개인정보 보호 → 광고(기기에 따라 설정 → Google → 광고)에서 광고 ID 를 삭제하거나 재설정하실 수 있습니다. 삭제하시면 광고 네트워크에는 광고 ID 대신 0 으로만 채워진 값이 가며, 모든 기능은 그대로 쓰실 수 있습니다.
  • 우주 Pro 를 사신 뒤 — 광고 기능(광고 네트워크의 코드)을 켜지 않으며 추적 허용 창도 띄우지 않습니다.

유럽경제지역(EEA)·영국·스위스 이용자
이 지역에서는 위 광고 파트너(Unity, Liftoff, Meta)가 맞춤 광고에 기기를 써도 되는지 광고를 요청하기 전에 앱 안에서 먼저 여쭙니다. 「거부」는 「동의」만큼 쉽게 고르실 수 있고, 어느 쪽이든 모든 기능을 그대로 쓰시며 광고도 표시됩니다. 거부하시면 맞춤이 아닌 광고만 나갑니다. 맞춤 광고는 이용자의 동의(GDPR 제6조 제1항 a호)에, 맞춤이 아닌 광고 표시와 광고 오작동 방어(2항)는 정당한 이익(같은 항 f호)에 근거합니다. 선택은 앱의 설정 > 맞춤 광고 설정에서 언제든 바꾸거나 철회하실 수 있고, 다음 광고 요청부터 적용됩니다. iPhone 에서는 추적 허용 요청(ATT)을 먼저 띄우고, 허용하신 경우에만 이 질문이 이어집니다. 허용하지 않으시면 이 질문 없이 맞춤이 아닌 광고만 나갑니다. 광고 네트워크는 표준계약조항 등 자체 보호 장치에 따라 정보를 미국 등으로 옮길 수 있습니다.

광고 네트워크의 개인정보 처리는 해당 업체의 방침을 따릅니다 — Unity/LevelPlay 개인정보 처리방침 · Liftoff 개인정보 처리방침 · Meta 개인정보 처리방침.

우주 Pro 는 한 번 사면 평생 쓰는 결제입니다(구독이 아니며 자동 갱신되지 않습니다). 결제는 App Store·Google Play 가 처리하며, 카드번호 같은 결제 정보는 애플·구글이 직접 받아 처리합니다. 저희는 보지도, 받지도, 보관하지도 않습니다. 구입을 복원할 때는 앱이 기기의 스토어에 구입 여부만 확인합니다. iPhone 이용 약관은 Apple 의 표준 사용권 계약(EULA)을 따릅니다.

5. 앱이 밖으로 보내는 요청 — 전부

  • 앱 상태 파일 — 앱이 켜질 때 저희 웹사이트(Netlify 호스팅)의 작은 파일 하나를 읽어 지금 판을 꼭 업데이트해야 하는지와 광고 설정(광고를 급히 꺼야 할 때 쓰는 값)을 확인합니다. 이 요청은 파일을 받아 오기만 하고 이용자에 관한 값은 싣지 않습니다. 여느 웹페이지처럼 호스팅 서버 기록에 접속 IP 주소가 남을 수 있습니다. 연결이 없으면 확인을 건너뜁니다.
  • 광고 요청 — 우주 Pro 를 사지 않은 이용자는 앱을 켤 때 광고 네트워크에 연결하고, 광고를 고를 수 있는 창이 열리면 광고를 미리 받아 둡니다(4항). 우주 Pro 를 사신 뒤에는 광고 네트워크에 연결하지 않습니다.
  • 스토어 결제 — 가격을 보여 주거나 사거나 구입을 복원할 때 기기의 App Store·Google Play 와 통신합니다.
  • 결제 알림(Android 만) — Android 에서 결제가 끝나는 순간, 개발자에게 「하나 팔렸다」를 알리는 요청 한 번을 저희 서버로 보냅니다. 실리는 값은 앱 이름·플랫폼·상품(이름과 ID)·금액·결제 시각·구매 토큰(Google Play 가 이 결제에 붙이는 값)뿐이고, 이름·연락처·기기 식별자는 실리지 않습니다. 서버는 이 내용을 개발자의 메신저로 한 줄 전달합니다. 구매 토큰은 같은 알림이 두 번 가지 않게 거르는 데에만 잠시 쓰며 따로 저장하지 않습니다. 서버 기록에는 접속 IP 주소의 일부, 접속한 프로그램 정보, 구매 토큰의 앞부분이 남을 수 있습니다. iPhone 에서는 이 요청을 보내지 않습니다.
  • 이용자가 직접 누르는 링크 — 「리뷰 남기기」(App Store 또는 Google Play), 「개인정보 처리방침」(이 페이지, GitHub Pages), 「문의·제보」(메일 앱)는 기기에서 열리며, 그다음부터는 그 서비스의 방침이 적용됩니다.

그림과 별 자료가 모두 앱 안에 있어 인터넷 없이도 둘러볼 수 있습니다.

6. 제3자 제공 · 국외 이전 · 판매

개인정보를 판매하지 않습니다. 필요한 정보는 아래 광고 사업자, Apple·Google(결제), Render(결제 알림 서버), Netlify(앱 상태 파일), GitHub Pages(방침), 개발자의 메신저 서비스가 처리합니다. 호스팅 업체는 IP·요청 시각·접속 프로그램 정보를, 결제 알림 서버는 5항의 정보를 처리합니다. 메신저에는 상품·금액 등의 알림을 전달하며 구매 토큰은 알림 문구에 넣지 않습니다. 처리 시 네트워크로 국외 서버에 전송될 수 있으며 국가·보관 기간은 각 사업자의 방침에 따릅니다.

7. 보관 기간과 삭제

기기 데이터는 삭제·초기화할 때까지, 문의 메일은 답변·문제 해결에 필요한 동안 보관한 뒤 삭제합니다. 결제 알림 중복 방지용 구매 토큰은 서버 메모리에서 최대 500개까지 보관하고 오래된 항목 교체 또는 서버 재시작 시 없어집니다. 서버 로그·메신저 알림이 함께 삭제되는 것은 아닙니다. 로그는 운영·보안에, 알림은 결제 확인·문의 대응에 필요한 동안 처리하며, 외부 기록에는 각 사업자의 보유·삭제 정책도 적용됩니다. 법령상 보존 의무가 있으면 해당 기간 보관합니다. 보유 정보 삭제는 아래 이메일로 요청하실 수 있습니다. 광고 ID 재설정·앱 삭제·Pro 구매는 이미 전송된 데이터를 삭제하지 않습니다. 광고 데이터 삭제는 광고 사업자에게 요청하시며 저희도 요청 경로를 안내해 드립니다. 상태 확인·결제 알림은 HTTPS로 전송합니다.

9. 아동

앱은 만 13세 미만 아동을 대상으로 하지 않으며, 저희는 아동의 개인정보를 알면서 수집하지 않습니다. 광고 식별자는 추적 허용을 끄시거나(iPhone) 광고 ID 를 삭제하시면(Android) 맞춤 광고에 쓰이지 않습니다.

  • 광고 — 맞춤 광고는 동의하신 경우에만 보여 드립니다(6조 1항 a호). 비맞춤 광고와 광고 부정 사용 방지는 정당한 이익(6조 1항 f호)에 근거합니다. 위에 적은 광고 네트워크는 각자의 방침에 따라 독립된 책임자로서 이 정보를 처리합니다. 동의는 위에 적은 앱 안의 맞춤 광고 설정에서 언제든 철회할 수 있으며, 철회해도 그 전의 처리에는 영향이 없습니다.
  • 아래 이메일로 열람·정정·삭제·처리정지·동의 철회와 적용 법령에 따른 이동·처리 제한·이의 제기를 요청하실 수 있습니다. 기록 확인에 필요한 최소한의 정보만 요청하고, 법적 보존 의무 등으로 삭제할 수 없으면 이유를 안내합니다. 계정을 만들지 않으므로 탈퇴 절차는 없습니다.
  • 자동화된 결정 없음 — 자동 처리만으로 법적 효과나 그에 준하는 중대한 영향을 주는 결정을 하지 않습니다.
  • 아동 — 사는 나라에서 온라인 서비스에 보호자 동의가 필요한 나이(유럽경제지역은 13~16세, 영국은 13세) 미만이라면 보호자의 허락 없이 맞춤 광고에 동의하지 마세요. 그런 동의 없이 아동의 정보를 갖고 있음을 알게 되면 지웁니다.
  • 국외 이전 — 광고 네트워크와 애플·구글은 EU–미국 데이터 프라이버시 프레임워크나 표준계약조항 같은 각자의 보호 장치에 따라 미국 등 이용자 나라 밖으로 정보를 옮길 수 있습니다.
  • 민원 — 사시거나 일하시는 나라의 개인정보 감독기관에 민원을 낼 수 있습니다.
