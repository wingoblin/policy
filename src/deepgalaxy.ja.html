3. アクセス権限

権限必要な理由
トラッキングの許可（任意、iPhone ATT）パーソナライズ広告のために広告識別子（IDFA）を使うため（第4項）。拒否してもアプリはすべてそのまま動作し、パーソナライズ広告の代わりに一般的な広告が表示されます
広告 ID（Android、インストール時に自動で許可）広告ネットワークがデバイスの広告 ID を読み取り、広告を表示して成果を測定するため（第4項）。確認画面は表示されず、デバイスの設定でいつでもリセットまたは削除できます（第4項）
インターネット・ネットワーク状態（インストール時に自動で許可）アプリの状態ファイル・広告・ストアでの購入と通信するため（第5項）

カメラ・マイク・写真・位置情報・連絡先・カレンダー・ヘルスケア情報にはアクセスせず、これらの権限も求めません。

4. 広告・決済

  • 広告は一か所だけです — 無料の天体（太陽・水星・金星・地球・月・火星・木星と木星の衛星）を見に行くときに、「広告を見て行く」をご自身で選んだ場合にだけ再生されるリワード動画広告です。最後までご覧いただくと、その天体へ移動します。アプリを開いたときや画面を移るときに勝手に出る広告や、バナー広告はありません。
  • 広告ネットワーク — Unity の LevelPlay（旧 ironSource）を通じて広告が表示され、広告パートナーは Unity Ads、Liftoff と Meta Audience Network です。
  • 読み取られるもの — 広告識別子（IDFA・IDFV／Android 広告 ID・App Set ID）、デバイス・OS・アプリのバージョン・言語などのデバイス情報、接続 IP から推定したおおよその国・都市、広告の表示・タップの記録、広告コードの動作記録。これらの値は広告ネットワークが利用者のデバイスから直接読み取り、当方は受け取ることも保管することもありません。
  • インストール済みアプリの情報（Android） — 広告事業者のコードが、デバイスにどのアプリがインストールされているかを確認することがあります。広告経由でインストールされたかを数えたり、すでにインストールしたアプリの広告を再び表示しないために使われます。
  • トラッキングの同意 — 宇宙 Pro を購入していない利用者がアプリを初めて開くと、Apple のトラッキング許可のリクエスト（ATT）が一度表示されます。許可しない場合はパーソナライズされていない広告が表示され、すべての機能をそのままお使いいただけます。許可するかどうかは設定 → プライバシーとセキュリティ → トラッキングでいつでも変更できます。
  • Android の広告 ID をオフにする — Android にはトラッキング許可の画面がありません。パーソナライズ広告を望まない場合は、設定 → プライバシー → 広告（デバイスによっては設定 → Google → 広告）で広告 ID を削除またはリセットできます。削除すると、広告ネットワークには広告 ID の代わりに 0 だけが並んだ値が送られ、すべての機能をそのままお使いいただけます。
  • 宇宙 Pro のご購入後 — 広告の機能（広告ネットワークのコード）を起動せず、トラッキング許可の画面も表示しません。

欧州経済領域（EEA）・英国・スイスの利用者
これらの地域では、上記の広告パートナー（Unity、Liftoff、Meta）がパーソナライズ広告のためにデバイスを使ってよいかを、広告をリクエストする前にアプリ内で先にお尋ねします。「拒否」は「同意」と同じくらい簡単に選べ、どちらを選んでもすべての機能をそのままお使いいただけ、広告も表示されます。拒否した場合はパーソナライズされていない広告だけが表示されます。パーソナライズ広告は利用者の同意（GDPR 第6条第1項(a)）に、パーソナライズされていない広告の表示と広告の誤作動防止（第2項）は正当な利益（同項(f)）に基づきます。選択はアプリの設定 > 広告のプライバシーでいつでも変更または撤回でき、次の広告リクエストから適用されます。iPhone ではトラッキング許可のリクエスト（ATT）を先に表示し、許可した場合にだけこの質問が続きます。許可しない場合は、この質問なしにパーソナライズされていない広告だけが表示されます。広告ネットワークは標準契約条項など独自の保護措置に従い、情報を米国などへ移転することがあります。

広告ネットワークによる個人情報の取り扱いは、各社のポリシーに従います — Unity/LevelPlay プライバシーポリシー · Liftoff プライバシーポリシー · Meta プライバシーポリシー。

宇宙 Pro は一度買えばずっと使える買い切りの購入です（サブスクリプションではなく、自動更新されません）。決済は App Store・Google Play が処理し、カード番号などの決済情報は Apple・Google が直接受け取って処理します。当方は見ることも、受け取ることも、保管することもありません。購入を復元するときは、アプリがデバイスのストアに購入の有無を確認するだけです。iPhone の利用規約は Apple の標準使用許諾契約（EULA）に従います。

5. アプリが外部に送るリクエスト — すべて

  • アプリ状態ファイル — アプリの起動時に当方のウェブサイト（Netlify でホスト）の小さなファイルを一つ読み込み、今のバージョンを必ずアップデートすべきかどうかと広告設定（広告を急いで止める必要があるときに使う値）を確認します。このリクエストはファイルを受け取るだけで、利用者に関する値は送りません。一般的なウェブページと同様に、ホスティングサーバーの記録に接続元の IP アドレスが残ることがあります。接続がない場合は確認を省略します。
  • 広告リクエスト — 宇宙 Pro を購入していない利用者の場合、アプリの起動時に広告ネットワークに接続し、広告を選べる画面が開いたときに広告を先読みしておきます（第4項）。宇宙 Pro のご購入後は広告ネットワークに接続しません。
  • ストアでの決済 — 価格の表示、購入、購入の復元のときに、デバイスの App Store・Google Play と通信します。
  • 購入の通知（Android のみ） — Android で決済が完了した瞬間、開発者に「一つ売れた」と知らせるリクエストを一回、当方のサーバーに送ります。含まれる値はアプリ名・プラットフォーム・商品（名前と ID）・金額・決済時刻・購入トークン（Google Play がこの決済に付ける値）だけで、名前・連絡先・デバイス識別子は含まれません。サーバーはこの内容を開発者のメッセンジャーに一行で転送します。購入トークンは同じ通知が二度届かないようにするためだけに一時的に使い、別途保存はしません。サーバーの記録には接続元 IP アドレスの一部、接続したプログラムの情報、購入トークンの先頭部分が残ることがあります。iPhone ではこのリクエストを送りません。
  • 利用者がご自身でタップするリンク — 「レビューを書く」（App Store または Google Play）、「プライバシーポリシー」（このページ、GitHub Pages）、「お問い合わせ」（メールアプリ）はデバイス上で開き、その先ではそのサービスのポリシーが適用されます。

画像と星のデータはすべてアプリ内にあるため、インターネットがなくても見て回れます。

7. 保管期間と削除

端末データは消去まで、問い合わせメールは回答・解決に必要な間保持し、その後削除します。重複防止用購入トークンはサーバーメモリーのみで最大500件、古い項目の除外か再起動で消えます。ログ・メッセージはこれでは消えません。ログは運用・安全管理、通知は購入確認・支援に必要な間処理し、外部記録には各社の保存・削除方針も適用されます。法定保存義務があればその期間保持します。保有情報の削除はメールで請求できます。広告ID再設定・アプリ削除・Pro購入は送信済み情報を削除しません。広告データは広告事業者へ削除請求してください。当方も窓口を案内します。状態確認・購入通知はHTTPSで送信します。

8. 画像とデータ
